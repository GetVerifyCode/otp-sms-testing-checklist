# Contributing

Thanks for improving this checklist.

## What belongs here

- Concrete QA checks that apply to most SMS OTP implementations
- Clarifications that reduce false passes
- Links to standards or public guidance (NIST, OWASP, carrier docs)

## What does not belong here

- Vendor sales copy or unverifiable success rates
- Advice to bypass a platform’s own rules
- Personal phone numbers, API keys, or private logs

## Pull requests

1. Keep items short and testable.
2. Prefer checkboxes over prose.
3. Update `CHECKLIST.md`, `README.md`, and the docs site in [GetVerifyCode.github.io](https://github.com/GetVerifyCode/GetVerifyCode.github.io) together when the checklist changes.
4. For matrix rows, also update `docs/test-matrix.md`.
